# Sai Manjari Embroidery

A modern, professional website for Sai Manjari Embroidery showcasing custom embroidery services including Computer Works, Maggam Work, and Computer Embroidery.

## 🎨 Features

- **Modern Design**: Clean, professional interface with soft blue (#B3CFE5) color scheme
- **Responsive**: Fully optimized for mobile, tablet, and desktop
- **Animations**: GSAP-powered text animations and 3D particle effects
- **Services Showcase**: Detailed presentation of all embroidery services
- **Contact Integration**: Direct links to Instagram, WhatsApp, and Google Maps
- **Admin Panel**: Secure admin area for managing designs (Supabase-powered)

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (React 19)
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Three.js
- **Database**: Supabase
- **Image Management**: Cloudinary
- **Deployment**: Vercel

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🌐 Deployment

See [deploy-to-vercel.md](./deploy-to-vercel.md) for detailed deployment instructions.

Quick deploy:
```bash
vercel --prod
```

## 📝 Environment Variables

Create a `.env.local` file with:

```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-key
JWT_SECRET=your-jwt-secret
CLOUDINARY_CLOUD_NAME=your-cloudinary-name
CLOUDINARY_API_KEY=your-cloudinary-key
CLOUDINARY_API_SECRET=your-cloudinary-secret
NEXTAUTH_SECRET=your-nextauth-secret
NEXTAUTH_URL=http://localhost:3000
```
